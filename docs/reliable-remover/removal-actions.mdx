The `action` decides what happens to the items your rule matches.

| Action | What it does |
| :--- | :--- |
| [`remove`](#remove) | Removes the item from the game entirely. |
| [`remove_creative`](#remove_creative) | Hides it from creative tabs and recipe viewers. |
| [`remove_recipe`](#remove_recipe) | Hides recipes that craft it. |
| [`remove_info`](#remove_info) | Hides its info page in EMI/JEI/RRV. |
| [`remove_inventory`](#remove_inventory) | Deletes it from player inventories. |
| [`remove_storage`](#remove_storage) | Deletes it from chests, barrels, etc. when opened. |
| [`remove_drops`](#remove_drops) | Deletes it when it's dropped on the ground. |
| [`remove_equipment`](#remove_equipment) | Takes it away from mobs. |
| [`remove_loot`](#remove_loot) | Stops it from coming from any loot table (chests, mobs, blocks, fishing). |
| [`remove_chest_loot`](#remove_chest_loot) | Stops it from generating in loot chests only. |
| [`remove_trade`](#remove_trade) | Removes villager trades that use it. |
| [`remove_interactions`](#remove_interactions) | Stops players from right-clicking it. |
| [`remove_placement`](#remove_placement) | Stops players from placing it. |
| [`remove_attacks`](#remove_attacks) | Stops players from attacking with it. |
| [`remove_hand_swing`](#remove_hand_swing) | Stops the swing animation when using it. |
| [`remove_enchantment`](#remove_enchantment) | Removes an enchantment from loot, tables, trades and books. |
| [`remove_potion`](#remove_potion) | Hides potions and tipped arrows with an effect. |
| [`remove_effect`](#remove_effect) | Stops a status effect from being applied, or swaps it. |

## Removing items

### `remove`

Does everything: hides the item from creative tabs and recipe viewers, removes its recipes and tags, and deletes it from inventories, chests, the ground, loot, trades and mobs.

```json
{
  "action": "remove",
  "items": ["minecraft:tnt"]
}
```

You can turn individual parts of this off (for example, keep removed items in recipe viewers) in [Settings](/project/reliable-remover/latest/docs/reliable-remover/settings).

[More `remove` examples](/project/reliable-remover/latest/docs/reliable-remover/examples/basic-removal)

### `remove_creative`

Hides the item from creative tabs and recipe viewers, but it still works normally. Good for items you give out with commands.

Also works on status effects, which hides them from effect viewers like JEED.

```json
{
  "action": "remove_creative",
  "items": ["minecraft:command_block"],
  "effects": ["minecraft:wither"]
}
```

### `remove_recipe`

Hides every recipe that makes the item. The item itself stays. Players just can't craft it.

```json
{
  "action": "remove_recipe",
  "items": ["minecraft:beacon"]
}
```

### `remove_info`

Hides the item's info page in EMI, JEI and RRV. The item itself stays visible.

```json
{
  "action": "remove_info",
  "items": ["quark:trowel"]
}
```

## Deleting items from the world

These four can also **swap** the item instead of deleting it. Add `replace_with`, and players who pick up a Netherite Sword get a Diamond Sword instead:

```json
{
  "action": "remove_inventory",
  "items": ["minecraft:netherite_sword"],
  "replace_with": "minecraft:diamond_sword"
}
```

### `remove_inventory`

Deletes the item from player inventories as soon as they have it.

```json
{
  "action": "remove_inventory",
  "items": ["minecraft:bedrock"]
}
```

### `remove_storage`

Deletes the item from chests, barrels, shulker boxes and other containers when a player opens them.

```json
{
  "action": "remove_storage",
  "items": ["minecraft:tnt"]
}
```

### `remove_drops`

Deletes the item the moment it lands on the ground. Good for cutting down item lag.

```json
{
  "action": "remove_drops",
  "items": ["minecraft:cobblestone"]
}
```

### `remove_equipment`

Takes the item out of mobs' hands and armor slots, so they can't spawn with it or pick it up.

```json
{
  "action": "remove_equipment",
  "items": ["minecraft:netherite_sword"]
}
```

## Loot and trades

### `remove_loot`

Removes the item from **every** loot table: chests, mob drops, fishing, archaeology, and also block drops. Removing diamonds this way means diamond ore stops dropping them too.

```json
{
  "action": "remove_loot",
  "items": ["minecraft:enchanted_golden_apple"]
}
```

You can also remove any loot that comes with a certain enchantment:

```json
{
  "action": "remove_loot",
  "enchantments": ["minecraft:sharpness"]
}
```

### `remove_chest_loot`

Like `remove_loot`, but only for chests, barrels and other containers. Mob drops and block drops are untouched.

```json
{
  "action": "remove_chest_loot",
  "items": ["minecraft:diamond"]
}
```

### `remove_trade`

Removes any villager or wandering trader trade that buys or sells the item.

```json
{
  "action": "remove_trade",
  "items": ["minecraft:emerald"]
}
```

## Restricting use

### `remove_interactions`

Stops players from right-clicking with the item.

```json
{
  "action": "remove_interactions",
  "items": ["minecraft:flint_and_steel", "minecraft:lava_bucket"]
}
```

Use `blocks` instead to stop players from right-clicking a **placed** block. Players can still place it, they just can't use it. This lets you place beds and anvils but not sleep in or use them:

```json
{
  "action": "remove_interactions",
  "blocks": ["minecraft:anvil", "#minecraft:beds"]
}
```

[More interaction examples](/project/reliable-remover/latest/docs/reliable-remover/examples/interaction-blocking)

### `remove_placement`

Stops players from placing the block. They can still craft, hold and trade it.

```json
{
  "action": "remove_placement",
  "blocks": ["minecraft:tnt"]
}
```

### `remove_attacks`

Stops players from attacking while holding the item.

```json
{
  "action": "remove_attacks",
  "items": ["minecraft:stick"]
}
```

[More combat examples](/project/reliable-remover/latest/docs/reliable-remover/examples/combat-restrictions)

### `remove_hand_swing`

Stops the hand swing animation when using the item.

```json
{
  "action": "remove_hand_swing",
  "items": ["minecraft:stick"]
}
```

## Enchantments, potions and effects

### `remove_enchantment`

Stops an enchantment from appearing anywhere: loot, enchanting tables, villager trades and drops. If an enchanted book ends up with nothing left on it, it gets a different allowed enchantment, or turns into a plain book.

```json
{
  "action": "remove_enchantment",
  "enchantments": ["minecraft:mending", "#minecraft:curse"]
}
```

Add `items` to only remove it from those items. Fortune is removed from pickaxes, but not from other tools:

```json
{
  "action": "remove_enchantment",
  "enchantments": ["minecraft:fortune"],
  "items": ["#minecraft:pickaxes"]
}
```

Or use `not` to keep it on certain items. Fortune is removed from everything except golden pickaxes:

```json
{
  "action": "remove_enchantment",
  "enchantments": ["minecraft:fortune"],
  "not": {
    "items": ["minecraft:golden_pickaxe"]
  }
}
```

### `remove_potion`

Hides every potion, splash potion, lingering potion and tipped arrow with the effect, in creative tabs, recipe viewers and loot.

```json
{
  "action": "remove_potion",
  "effects": ["minecraft:poison", "minecraft:invisibility"]
}
```

This only hides the potion items. To stop the effect itself (from mobs, beacons, `/effect`, etc.), use `remove_effect`.

### `remove_effect`

Stops a status effect from being applied to anything, from any source: potions, mob attacks, beacons, `/effect give`, and so on.

```json
{
  "action": "remove_effect",
  "effects": ["minecraft:poison"]
}
```

Add `replace_with` to swap it for a different effect instead. Here, anything that would give Poison gives Slowness with the same duration and level. Potion tooltips show Slowness too.

```json
{
  "action": "remove_effect",
  "effects": ["minecraft:poison"],
  "replace_with": "minecraft:slowness"
}
```

## Alternate names

Most actions accept a few spellings, so `remove_trades`, `remove_drop` and `remove_loot_table` all work. For example, `remove_effect` also accepts `remove_effects`, `remove_status_effect` and `remove_mob_effect`.
