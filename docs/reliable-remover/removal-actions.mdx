There are many actions you can apply to items.

### `remove`

The nuclear option.
This completely scrubs the item from the game context based on your global config.

* Removes from Creative Tabs, EMI/JEI/REI, Loot tables, and Villager trades.
* Deletes from player inventories and world drops.

[View 'Basic Removal' Examples](/project/reliable-remover/docs/reliable-remover/examples/basic-removal)

### `remove_interactions`

Prevents the player from "using" the item (Right-Click).

* **Use Case**: Useful if you want an item to exist for crafting but not be usable (e.g., banning a specific wand, tool, or bucket).

[View 'Interaction Blocking' Examples](/project/reliable-remover/docs/reliable-remover/examples/interaction-blocking)

### `remove_attacks`

Prevents the player from attacking entities while holding the specified item.

* **Use Case**: Disable specific weapons or protect specific entities from being hurt.

[View 'Combat Restrictions' Examples](/project/reliable-remover/docs/reliable-remover/examples/combat-restrictions)

### `remove_enchantment`

Hides any item (Enchanted Book, Tool, Armor) that contains the specified enchantment.

* **Use Case**: Remove "Protection" or specific curses from the game entirely.

```json
{
  "action": "remove_enchantment",
  "items": ["minecraft:protection", "minecraft:mending"]
}

```

### `remove_potion`

Hides any Potion, Splash Potion, Lingering Potion, or Tipped Arrow containing the specified Potion effect.

* **Use Case**: Remove "Poison" or "Invisibility" potions from the game.

```json
{
  "action": "remove_potion",
  "items": ["minecraft:poison", "minecraft:strong_poison"]
}

```

###`remove_hand_swing`

Prevents the player from swinging their hand while holding the specified item.

* **Use Case**: Useful for disabling the "swing" animation for items that shouldn't appear to be used as tools or weapons.

```json
{
  "action": "remove_hand_swing",
  "items": ["minecraft:stick"]
}

```
