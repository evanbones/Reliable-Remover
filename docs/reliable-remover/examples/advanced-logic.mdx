## Effects and potions

### No poison, from anything

Covers potions, cave spiders, `/effect`, and every other source:

```json
{
  "action": "remove_effect",
  "effects": ["minecraft:poison"]
}
```

### Poison becomes slowness

Same duration and level. Potion tooltips show Slowness too:

```json
{
  "action": "remove_effect",
  "effects": ["minecraft:poison"],
  "replace_with": "minecraft:slowness"
}
```

### Hide night vision potions

Removes drinkable, splash and lingering Night Vision potions, plus tipped arrows, from creative tabs, recipe viewers and loot. The effect itself still works (e.g. from commands):

```json
{
  "action": "remove_potion",
  "effects": ["minecraft:night_vision"]
}
```

## Enchantments

### No Mending or curses anywhere

```json
{
  "action": "remove_enchantment",
  "enchantments": ["minecraft:mending", "#minecraft:curse"]
}
```

### Fortune only on golden pickaxes

```json
{
  "action": "remove_enchantment",
  "enchantments": ["minecraft:fortune"],
  "not": {
    "items": ["minecraft:golden_pickaxe"]
  }
}
```

### No Sharpness gear in loot

Removes any loot item that comes enchanted with Sharpness:

```json
{
  "action": "remove_loot",
  "enchantments": ["minecraft:sharpness"]
}
```

## Item data

See [Item data](/project/reliable-remover/latest/docs/reliable-remover/filtering#item-data-components--nbt) for the full syntax.

### Remove Mending books only

Other enchanted books are left alone.

1.21+:

```json
{
  "action": "remove",
  "items": ["minecraft:enchanted_book"],
  "components": ["[stored_enchantments~[{enchantments:\"minecraft:mending\"}]]"]
}
```

1.20.1:

```json
{
  "action": "remove",
  "items": ["minecraft:enchanted_book"],
  "nbt": ["{StoredEnchantments:[{id:\"minecraft:mending\"}]}"]
}
```

### Remove items your datapack marked as banned (1.21+)

Any item given with `/give @s stick[custom_data={my_pack:{banned:true}}]` gets removed:

```json
{
  "action": "remove",
  "components": ["[custom_data~{my_pack:{banned:true}}]"]
}
```

### Remove items by custom model data (1.20.1)

```json
{
  "action": "remove",
  "nbt": ["{CustomModelData:1}", "{CustomModelData:2}"]
}
```
