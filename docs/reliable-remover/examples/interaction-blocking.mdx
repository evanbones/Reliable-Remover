title: Blocking Interactions
hide_meta: true
---

These examples use the `remove_interactions` action. The item still exists and can be crafted, but cannot be "used" (right-clicked).

### Disable Item Usage
Prevents players from using Lava Buckets or Flint and Steel.

```json
{
  "action": "remove_interactions",
  "items": [
    "minecraft:lava_bucket",
    "minecraft:flint_and_steel"
  ]
}

```

### Prevent Interaction with Specific Entities

Prevents players from using a Saddle on a Pig. Other interactions with Saddles (like on Horses) remain unaffected.

```json
{
  "action": "remove_interactions",
  "items": [
    "minecraft:saddle"
  ],
  "entities": [
    "minecraft:pig"
  ]
}

```
