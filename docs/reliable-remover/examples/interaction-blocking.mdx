---
title: Blocking Interactions
hide_meta: true
---

These keep the item in the game, but stop players from using it.

### Can't use lava buckets or flint and steel

```json
{
  "action": "remove_interactions",
  "items": ["minecraft:lava_bucket", "minecraft:flint_and_steel"]
}
```

### Can place beds and anvils, but can't use them

```json
{
  "action": "remove_interactions",
  "blocks": ["minecraft:anvil", "#minecraft:beds"]
}
```

### Can't place TNT

Players can still craft, carry and trade it:

```json
{
  "action": "remove_placement",
  "blocks": ["minecraft:tnt"]
}
```

### Can't saddle pigs

Saddles still work on horses:

```json
{
  "action": "remove_interactions",
  "items": ["minecraft:saddle"],
  "entities": ["minecraft:pig"]
}
```

### Can't shear sheep

Shears still work on leaves, vines, etc.:

```json
{
  "action": "remove_interactions",
  "items": ["minecraft:shears"],
  "entities": ["minecraft:sheep"]
}
```

### No swing animation for shovels and pickaxes

```json
{
  "action": "remove_hand_swing",
  "patterns": ["/.*_shovel/", "/.*_pickaxe/"]
}
```
