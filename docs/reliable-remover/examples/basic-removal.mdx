---

These examples use the `remove` action. This effectively deletes the item from the game, removing it from the creative tabs, recipe viewers, loot tables, and recipes/tags (when [Reliable Recipes](https://modrinth.com/mod/reliable-recipes) is installed).

### Remove Specific Items
Removes TNT and Bedrock from the game completely.

```json
{
  "action": "remove",
  "filter": {
    "items": [
      "minecraft:tnt",
      "minecraft:bedrock"
    ]
  }
}

```

### Remove an Entire Mod

Removes all items belonging to `farmersdelight`.

```json
{
  "action": "remove",
  "filter": {
    "mod": [
      "farmersdelight"
    ]
  }
}

```

### Remove Items by Regex Pattern

Removes all Swords from any mod.

```json
{
  "action": "remove",
  "filter": {
    "pattern": "/.*_sword/"
  }
}

```
