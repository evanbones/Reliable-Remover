These examples use the `remove` action. This effectively deletes the item from the game, removing it from the creative tabs, recipe viewers, loot tables, and recipes/tags.

### Remove Specific Items
Removes TNT and Bedrock from the game completely.

```json
{
  "action": "remove",
  "items": [
    "minecraft:tnt",
    "minecraft:bedrock"
  ]
}

```

### Remove an Entire Mod

Removes all items belonging to `farmersdelight`.

```json
{
  "action": "remove",
  "mod": [
    "farmersdelight"
  ]
}

```

### Remove Items by Regex Pattern

Removes all Swords from any mod.

```json
{
  "action": "remove",
  "pattern": "/.*_sword/"
}

```

### Remove Items by Tag

Removes all logs from the game by targeting their item tag.

```json
{
  "action": "remove",
  "tags": [
    "minecraft:logs"
  ]
}

```

### Remove an Item but Salvage its Recipes

Removes Diamonds from the game completely, but replaces them with Emeralds in all crafting recipes, furnace recipes, and machine outputs.

```json
{
  "action": "remove",
  "items": [
    "minecraft:diamond"
  ],
  "replace_with": "minecraft:emerald"
}

```

### Replace an Item with a Modified Item (1.21+)

Replaces Netherite Swords with a half-broken Diamond Sword that has its enchantments removed.
The components use the same syntax as the `/give` command. See [Modifying the Replacement Item](/project/reliable-remover/latest/docs/reliable-remover/filtering#modifying-the-replacement-item) for details.

```json
{
  "action": "remove",
  "items": [
    "minecraft:netherite_sword"
  ],
  "replace_with": "minecraft:diamond_sword[damage=500,!enchantments]"
}

```
