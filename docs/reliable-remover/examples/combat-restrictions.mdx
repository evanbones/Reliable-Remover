---
title: Combat Restrictions
hide_meta: true
---

These use `remove_attacks` to stop players from hitting things.

### Can't attack with a stick

```json
{
  "action": "remove_attacks",
  "items": ["minecraft:stick"]
}
```

### Can't attack with any sword or axe

```json
{
  "action": "remove_attacks",
  "patterns": ["/.*_sword/", "/.*_axe/"]
}
```

### Can't use one mod's weapons

```json
{
  "action": "remove_attacks",
  "mod": ["simplyswords"]
}
```

### Can't hurt villagers or iron golems

No items listed, so this applies to every item. (Punching with an empty hand still works.)

```json
{
  "action": "remove_attacks",
  "entities": ["minecraft:villager", "minecraft:iron_golem"]
}
```

### Zombies can't spawn with diamond swords

Players can still use them:

```json
{
  "action": "remove",
  "items": ["minecraft:diamond_sword"],
  "entities": ["minecraft:zombie"]
}
```

### Skeletons can't wear helmets

```json
{
  "action": "remove",
  "patterns": ["/.*_helmet/"],
  "entities": ["minecraft:skeleton"]
}
```

### No mob spawns with netherite gear

```json
{
  "action": "remove_equipment",
  "patterns": ["/minecraft:netherite_.*/"]
}
```
