---

* Disable only specific actions, such as attacking or interacting (right-clicking) with an item.
* Remove items by ID, mod ID, tag, regex patterns, or item data (Data Components on 1.21+, NBT on 1.20.1).
* Configure global settings via [YACL](https://modrinth.com/mod/yacl) to toggle messages, removal behavior, and more.
* Restrict items or interactions only in specific dimensions (e.g., make an item usable only in the Nether).
* Automatically hides items from:
    * Creative mode tabs.
    * [EMI](https://modrinth.com/mod/emi)/[JEI](https://modrinth.com/mod/jei)/[RRV](https://modrinth.com/mod/rrv) (including Info tabs).
    * Player inventories.
    * Villager trades.
    * Loot tables.
    * Mob equipment (armor and held items).
