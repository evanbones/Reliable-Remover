| Command | What it does |
| :--- | :--- |
| `/rremover hand` | Shows the ID of the item in your hand. |
| `/rremover hotbar` | Shows the IDs of everything in your hotbar and offhand. |
| `/rremover inventory` | Shows the IDs of everything in your inventory, including armor. |
| `/rremover remove <id>` | Removes an item without editing any files. |
| `/rremover undo <id>` | Brings back an item you removed with `/rremover remove`. |
| `/rremover folder` | Opens the `config/reliable_remover/` folder. |

`remove`, `undo` and `folder` need operator permissions.

## Copying IDs

`hand`, `hotbar` and `inventory` print a list you can paste straight into a rule:

```text
/rremover hotbar
→ ["minecraft:tnt", "minecraft:bedrock", "minecraft:lava_bucket"]
```

Click the green text in chat to copy it.

**Banning a bunch of items at once:**

1. Put everything you want to ban in your inventory.
2. Run `/rremover inventory` and click the result to copy it.
3. Paste it into a rule:

```json
{
  "action": "remove",
  "items": ["minecraft:tnt", "minecraft:bedrock", "minecraft:lava_bucket"]
}
```

## Quick removals

```text
/rremover remove minecraft:apple
/rremover undo minecraft:apple
```

These don't touch your rule files. The item goes into the `blacklistedItems` list in `config/reliable_remover.json` instead. Run `/reload` afterwards (or turn on **Reload After Removal** in [Settings](/project/reliable-remover/latest/docs/reliable-remover/settings)).
