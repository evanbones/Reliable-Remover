## Your first rule

1. Open your instance's `config/reliable_remover/` folder. (In-game, `/rremover folder` opens it for you.)
2. Make a new file, e.g. `my_rules.json`. The name doesn't matter, as long as it ends in `.json`.
3. Paste this in:

```json
{
  "action": "remove",
  "items": ["minecraft:tnt"]
}
```

4. Save, then run `/reload` in-game. TNT is now gone.

The first time you launch, the mod creates `removal_example.json.disabled` in this folder. Files ending in `.disabled` are ignored, so rename it to `.json` if you want to use it.

## Getting item IDs

Hold the item and run `/rremover hand`. Click the green text in chat to copy the ID.

Need a lot of IDs at once? Put the items in your inventory and run `/rremover inventory`. You get a ready-to-paste list like `["minecraft:tnt", "minecraft:bedrock"]`. See [Commands](/project/reliable-remover/latest/docs/reliable-remover/commands).

## How a rule works

Every rule has an **action** (what to do) and **filters** (which items to do it to).

```json
{
  "action": "remove_attacks",
  "items": ["minecraft:stick"]
}
```

Here the action is `remove_attacks` and the filter is `items`, so players can't attack with sticks.

* [All actions](/project/reliable-remover/latest/docs/reliable-remover/removal-actions)
* [All filters](/project/reliable-remover/latest/docs/reliable-remover/filtering)

If you leave out `action`, the rule uses `remove`.

## Several rules in one file

Wrap them in `[ ]` and separate them with commas:

```json
[
  {
    "action": "remove",
    "items": ["minecraft:tnt"]
  },
  {
    "action": "remove_attacks",
    "items": ["minecraft:stick"]
  }
]
```

You can also make as many files as you like, and put them in subfolders. For example:

```text
config/reliable_remover/
├── vanilla.json
├── create/
│   └── nerfs.json
└── farmersdelight/
    └── removals.json
```

## Several actions in one rule

Use `actions` with a list to apply more than one action to the same items. With this rule, diamonds never show up in chests or villager trades, but you can still mine them:

```json
{
  "actions": ["remove_chest_loot", "remove_trade"],
  "items": ["minecraft:diamond"]
}
```
